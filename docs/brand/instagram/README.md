# Instagram kit: @snowway.app

## Files (this folder)
- `profile-pic.png`: 1080×1080, the site's mountain logo, safe for Instagram's circle crop.
- `highlight-forecasts.png`, `highlight-calendar.png`, `highlight-guides.png`: Story highlight covers (1080×1920).
  Post each as a story, add it to a highlight, then "Edit highlight → Edit cover" and pick it.

## Profile fields
- **Name** (searchable, so it carries keywords): `Snow Way | Ski Snow Forecasts`
- **Username:** `snowway.app`
- **Bio** (under 150 characters):
  ```
  Which ski resort is getting the most snow this week?
  ❄️ 7-day snow forecasts for 200+ resorts
  🗓 Free Powder Calendar ⬇️
  ```
- **Link:** `https://snowway.app/?utm_source=instagram&utm_medium=social&utm_campaign=bio`
  (the tag lets PostHog show visits from Instagram). Optional second link: `https://snowway.app/powder-calendar`
- **Account type:** Settings → Account type and tools → switch to **Professional → Creator**. Category: search **Website** (or pick **App page** from the list), and check "Show category on profile".
  Free, and it unlocks insights and the category label.

## More graphics (always current)
- snowway.app/admin → **Instagram images**: this week's snowiest resorts, brand card, Powder Calendar card, each as a post or a story.
- Direct links: `https://snowway.app/social/report.png` (add `?size=story` for stories), `/social/brand.png`, `/social/calendar.png`.
- Static copies in this folder: `brand-*.png`, `calendar-*.png`, `sample-report-*.png` (sample only; use the live link each Thursday).

## Highlights
1. **Forecasts**: weekly "snowiest resorts" stories.
2. **Calendar**: the Powder Calendar (best month per resort), with the link sticker to /powder-calendar.
3. **Guides**: Ikon vs Epic, first trip, Japan, the Alps, etc.

## First three posts
1. **Who's behind it.** A photo of you riding (powder jump or chairlift storm shot).
   "I built Snow Way to answer one question every winter: where's it dumping this week? 7-day snow forecasts for 200+ resorts,
   free, no app to download. Link in bio."
2. **This week's snowiest resorts.** Screenshot of snowway.app/powder-report (new every Thursday).
   "The 5 resorts getting the most snow in the next 7 days. Updated every Thursday. Full list in bio."
3. **Powder Calendar.** The calendar cover image (`app/assets/images/powder-calendar-cover.webp`).
   "Best month for powder at every major resort, on one page. Free download, link in bio."

## Every Thursday (5 minutes)
Screenshot the powder report → post it, and share it to your story with a link sticker to /powder-report.
Hashtags (pick 5–8): #skiing #snowboarding #powderday #skiseason #snowforecast plus the region (#coloradoskiing, #utahsnow, #tahoe).
